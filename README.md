После завершения синхронного фрагмента runtime освобождает стек, обрабатывает microtasks и продолжает фазы event loop. Поэтому порядок Promise, timer и `setImmediate` нельзя объяснять только временем задержки.

В контексте этого урока раздел связан с задачей: `AbortController` передаёт отмену через слои приложения; таймаут — частный случай отмены.

Продолжение работы после `uncaughtException` опасно: состояние процесса может быть повреждено. Процесс корректно завершают и доверяют перезапуск supervisor-платформе.
