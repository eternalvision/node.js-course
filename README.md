## 13. Введение в Socket.io

HTTP-запрос состоит из метода, target, заголовков и необязательного тела; ответ — из статуса, заголовков и тела. Сервер должен завершить каждую ветку ровно одним ответом.

### `server.mjs`

```js
import { WebSocketServer, WebSocket } from 'ws';
const wss = new WebSocketServer({ port: 8080 });
wss.on('connection', (socket) => {
  socket.isAlive = true;
  socket.on('pong', () => socket.isAlive = true);
  socket.on('message', (data) => {
    if (data.byteLength > 4096) return socket.close(1009, 'Message too large');
    for (const client of wss.clients) {
      if (client.readyState === WebSocket.OPEN) client.send(data);
    }
  });
});
setInterval(() => {
  for (const socket of wss.clients) {
    if (!socket.isAlive) socket.terminate();
    else { socket.isAlive = false; socket.ping(); }
  }
}, 30_000).unref();
```

## Критерии завершения урока

- Вы объясняете механизм без привязки к одному примеру.
- Вы понимаете границы встроенного API и внешней библиотеки.
- Вы умеете обработать ошибку, timeout и отмену.
- Вы можете проверить решение автоматическим тестом.
- Вы знаете, где найти статус и документацию использованного API.
