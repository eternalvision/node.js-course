# 4.3. Встроенное тестирование, coverage и диагностика

> Актуальная версия курса: Node.js 24 LTS, ECMAScript Modules и Express 5.

## О чём урок

Этот урок — самостоятельная глава курса. Материал построен от модели выполнения к проектным решениям: сначала разбираем, что делает платформа, затем пишем код, определяем отказоустойчивость и закрепляем результат практикой.

Старые примеры и устаревшие версии библиотек в эту редакцию не перенесены. Все объяснения сформулированы заново для современного Node.js.

## Как работать с материалом

1. Прочитайте раздел и сформулируйте его основную мысль своими словами.
2. До запуска примера предскажите результат и возможную ошибку.
3. Наберите код вручную, не вставляя его целиком.
4. Измените одно условие и объясните новое поведение.
5. Выполните мини-практику и ответьте на вопросы.
6. Сверьте нестабильный API с документацией Node.js 24.

## 1. node:test поддерживает suites, hooks, mocking, snapshots, watch mode и параллельный запуск

Тест проверяет наблюдаемое поведение и контракт ошибки, а не случайную внутреннюю последовательность вызовов. Это позволяет менять реализацию без переписывания всей suite.

Unit-тест изолирует чистую логику, integration-тест проверяет реальную границу, end-to-end проходит через публичный интерфейс.

В контексте этого урока раздел связан с задачей: `node:test` поддерживает suites, hooks, mocking, snapshots, watch mode и параллельный запуск.

Тест с реальным временем, случайностью или интернетом становится flaky и теряет доверие команды.

### `package.json`

```json
{
  "name": "lesson-4-modern-example",
  "private": true,
  "type": "module",
  "engines": {
    "node": ">=24 <25"
  },
  "scripts": {
    "start": "node slug.mjs",
    "test": "node --test"
  }
}
```

### `slug.mjs`

```js
export function slug(value) {
  if (typeof value !== 'string' || !value.trim()) throw new TypeError('value must be a non-empty string');
  return value.trim().toLowerCase().replaceAll(/[^\p{L}\p{N}]+/gu, '-').replaceAll(/^-|-$/g, '');
}
```

### `slug.test.mjs`

```js
import test from 'node:test';
import assert from 'node:assert/strict';
import { slug } from './slug.mjs';

test('normalizes a lesson title', () => {
  assert.equal(slug('  Node.js: тесты  '), 'node-js-тесты');
});
test('rejects empty input', () => {
  assert.throws(() => slug('  '), /non-empty/);
});
```
