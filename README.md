## О чём урок

Этот урок — самостоятельная глава курса. Материал построен от модели выполнения к проектным решениям: сначала разбираем, что делает платформа, затем пишем код, определяем отказоустойчивость и закрепляем результат практикой.

Старые примеры и устаревшие версии библиотек в эту редакцию не перенесены. Все объяснения сформулированы заново для современного Node.js.

## Как работать с материалом

1. Прочитайте раздел и сформулируйте его основную мысль своими словами.
2. До запуска примера предскажите результат и возможную ошибку.
3. Наберите код вручную, не вставляя его целиком.

6. Сверьте нестабильный API с документацией Node.js 24.

## 1. Встроенный fetch, WebSocket client, Web Streams, AbortController, Web Crypto и URL сближают серверные и браузерные API

WebSocket создаёт постоянный двунаправленный канал после HTTP Upgrade. Протокол приложения всё равно должен определить типы сообщений, идентификаторы, ошибки и версионирование.

Heartbeat обнаруживает полумёртвые соединения. Сервер отправляет ping, отмечает pong и завершает клиента, который не ответил в ожидаемом окне.

В контексте этого урока раздел связан с задачей: Встроенный `fetch`, WebSocket client, Web Streams, AbortController, Web Crypto и URL сближают серверные и браузерные API.

Неограниченный размер и частота сообщений позволяют одному соединению исчерпать CPU или память.

## 2. Type stripping запускает erasable TypeScript напрямую; он не проверяет типы и не заменяет tsc --noEmit в CI

Событие сообщает о произошедшем факте и обычно называется в прошедшем времени. Команда, напротив, выражает намерение и должна иметь явного владельца результата.

`emit` вызывает listeners синхронно в порядке регистрации. Асинхронная функция-listener возвращает Promise, но сам EventEmitter по умолчанию не ожидает его.

В контексте этого урока раздел связан с задачей: Type stripping запускает erasable TypeScript напрямую; он не проверяет типы и не заменяет `tsc --noEmit` в CI.

Скрытая цепочка событий затрудняет трассировку и тесты; для межсервисной доставки нужен брокер с подтверждением и повторной обработкой.

## 4. node:sqlite в Node 24 имеет статус release candidate: удобен для локальных инструментов и embedded-сценариев, но статус надо учитывать

Схема базы фиксирует инварианты ближе всего к данным: типы, NOT NULL, UNIQUE, CHECK и внешние ключи защищают все пути записи, а не только один HTTP-handler.

JOIN формирует строки на основе отношения таблиц. До написания запроса важно определить cardinality, иначе агрегаты легко умножатся.

В контексте этого урока раздел связан с задачей: `node:sqlite` в Node 24 имеет статус release candidate: удобен для локальных инструментов и embedded-сценариев, но статус надо учитывать.

Длинная транзакция удерживает locks и старые версии строк, увеличивает конфликтность и мешает обслуживанию.
