## 1. Основы веб-модуля и создание веб-сервера

HTTP-запрос состоит из метода, target, заголовков и необязательного тела; ответ — из статуса, заголовков и тела. Сервер должен завершить каждую ветку ровно одним ответом.

`node:http` создаёт request listener. Express использует тот же контракт и добавляет pipeline middleware, Router и методы формирования ответа.

В контексте этого урока раздел связан с задачей: HTTP — протокол сообщений: метод, target, заголовки, тело, статус и ответ.

Отсутствие лимита body, таймаутов или ограничения заголовков открывает путь к исчерпанию памяти и соединений.

## 2. Введение в веб-модуль Node.js

Формат файла определяется расширением и полем `type` в package.json. Смешивать ESM и CommonJS без явной границы нельзя: у них отличаются загрузка, значения служебных переменных и правила interop.

ESM разрешает спецификаторы до выполнения и загружает граф модулей с учётом циклических зависимостей. CommonJS выполняет `require` синхронно и экспортирует значение через `module.exports`.

В контексте этого урока раздел связан с задачей: Входящий запрос — Readable stream, ответ — Writable stream.

Неявное смешение форматов приводит к ошибкам загрузки, неожиданному default export и различиям между локальным запуском и тестами.

## 3. Обзор типовой архитектуры веб-приложений

Валидация подтверждает форму данных, параметризация защищает запрос, escaping защищает контекст вывода. Один слой не заменяет остальные.

CSRF актуален, когда браузер автоматически прикладывает cookie. Защита сочетает SameSite, проверку Origin/Referer и token для изменяющих запросов.

В контексте этого урока раздел связан с задачей: Маршрутизация сопоставляет метод и URL; `new URL(req.url, base)` безопаснее ручного разбора.

Разрешение CORS `*` вместе с неверной моделью credentials либо не работает, либо открывает лишний доступ.

### `server.mjs`

```js
import { createServer } from 'node:http';

const server = createServer((req, res) => {
  const url = new URL(req.url, 'http://localhost');
  if (req.method === 'GET' && url.pathname === '/health') {
    res.writeHead(200, { 'content-type': 'application/json; charset=utf-8' });
    return res.end(JSON.stringify({ status: 'ok' }));
  }
  res.writeHead(404, { 'content-type': 'application/problem+json' });
  res.end(JSON.stringify({ title: 'Not Found', status: 404 }));
});
server.listen(3000, () => console.log('http://localhost:3000'));
```
