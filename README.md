## О чём урок

Этот урок — самостоятельная глава курса. Материал построен от модели выполнения к проектным решениям: сначала разбираем, что делает платформа, затем пишем код, определяем отказоустойчивость и закрепляем результат практикой.

## 1. Реализация системы аутентификации и авторизации (Повторение)

Session cookie получает HttpOnly, Secure и подходящий SameSite. После login идентификатор регенерируют, после logout серверную сессию уничтожают.

## Цельный пример урока

Ниже приведён актуальный минимальный пример. Он размещён прямо в материале, чтобы теория и код не расходились по отдельным каталогам.

### `authorize.mjs`

```js
export function canEditProject(actor, project) {
  return actor.roles.includes('admin') || project.ownerId === actor.id;
}
export function requireProjectAccess(actor, project) {
  if (!actor) return { status: 401, reason: 'Authentication required' };
  if (!canEditProject(actor, project)) return { status: 403, reason: 'Forbidden' };
  return { status: 204 };
}
```
