## О чём урок

Этот урок — самостоятельная глава курса. Материал построен от модели выполнения к проектным решениям: сначала разбираем, что делает платформа, затем пишем код, определяем отказоустойчивость и закрепляем результат практикой.

## 1. Работа с файлами

Для прикладного асинхронного кода используется `node:fs/promises`. Синхронные функции допустимы в коротком CLI или на этапе запуска, но не в горячем пути HTTP-запроса.

FileHandle надо закрывать детерминированно. Высокоуровневые функции `readFile` и `writeFile` управляют handle сами, а низкоуровневый `open` передаёт ответственность вызывающему коду.

В контексте этого урока раздел связан с задачей: Предпочитайте `node:fs/promises`; синхронные операции допустимы при старте CLI, но не в обработчике запроса.

Path traversal позволяет выйти из разрешённого каталога через `..`, абсолютный путь или особенности платформы.

## 2. Общий обзор работы с файлами в Node.js.

Путь файловой системы и URL — разные модели. Путь строят через `node:path`, а ресурс рядом с ESM-модулем находят относительно `import.meta.url`.

FileHandle надо закрывать детерминированно. Высокоуровневые функции `readFile` и `writeFile` управляют handle сами, а низкоуровневый `open` передаёт ответственность вызывающему коду.

В контексте этого урока раздел связан с задачей: В ESM нет CommonJS-глобальных `__dirname` и `__filename`: используйте `import.meta.url` и `import.meta.dirname` в поддерживаемой версии.

## 4. Синхронные и Асинхронные Операции

Асинхронность описывает возможность продолжить полезную работу во время ожидания, а параллельность — одновременное исполнение на нескольких вычислительных ресурсах. В Node.js эти понятия связаны, но не тождественны.

Callback API часто использует соглашение error-first. При переводе в Promise важно сохранить ошибку, не вызвать resolve дважды и корректно освободить ресурсы.

В контексте этого урока раздел связан с задачей: Глобально доступны `fetch`, `Headers`, `Request`, `Response`, Web Crypto, URL, TextEncoder и Web Streams.

Забытый `await` превращает ожидаемую ошибку в необработанный rejection и может завершить запрос раньше фактической операции.
