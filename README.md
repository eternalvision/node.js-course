## О чём урок

Этот урок — самостоятельная глава курса. Материал построен от модели выполнения к проектным решениям: сначала разбираем, что делает платформа, затем пишем код, определяем отказоустойчивость и закрепляем результат практикой.

Старые примеры и устаревшие версии библиотек в эту редакцию не перенесены. Все объяснения сформулированы заново для современного Node.js.

## Как работать с материалом

1. Прочитайте раздел и сформулируйте его основную мысль своими словами.
2. До запуска примера предскажите результат и возможную ошибку.
3. Наберите код вручную, не вставляя его целиком.
4. Измените одно условие и объясните новое поведение.
5. Выполните мини-практику и ответьте на вопросы.
6. Сверьте нестабильный API с документацией Node.js 24.

```js
app.get('/health/ready', (req, res) => ready ? res.json({ status: 'ready' }) : res.sendStatus(503));
const server = app.listen(process.env.PORT ?? 3000);
process.on('SIGTERM', () => {
  ready = false;
  server.close((error) => process.exitCode = error ? 1 : 0);
});
```
