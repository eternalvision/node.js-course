## Подробный разбор

### Что создаёт express()

`express()` возвращает обработчик, совместимый с `node:http`. Express не заменяет HTTP: он организует цепочку middleware, маршрутизацию и удобные методы ответа. Поэтому сначала полезно понять чистый HTTP-сервер из урока 4.1.

### Как идёт запрос

Каждый middleware получает `(req, res, next)`. Он либо завершает ответ, либо вызывает `next()`, либо передаёт ошибку. Порядок регистрации равен порядку исполнения: parser ставят до handler, 404 — после маршрутов, error middleware — последним.

### Body и ответ

`express.json()` должен иметь разумный `limit`. Парсинг ещё не является валидацией: проверяйте типы и бизнес-ограничения отдельно. После `res.json`, `res.send` или `res.end` ответ завершён — возвращайтесь из handler, чтобы не отправить его повторно.
