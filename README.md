# 2.1. CLI, npm, package.json и конфигурация

> Актуальная версия курса: Node.js 24 LTS, ECMAScript Modules и Express 5.

## О чём урок

Этот урок — самостоятельная глава курса. Материал построен от модели выполнения к проектным решениям: сначала разбираем, что делает платформа, затем пишем код, определяем отказоустойчивость и закрепляем результат практикой.

Старые примеры и устаревшие версии библиотек в эту редакцию не перенесены. Все объяснения сформулированы заново для современного Node.js.

## Как работать с материалом

1. Прочитайте раздел и сформулируйте его основную мысль своими словами.
2. До запуска примера предскажите результат и возможную ошибку.
3. Наберите код вручную, не вставляя его целиком.
4. Измените одно условие и объясните новое поведение.
5. Выполните мини-практику и ответьте на вопросы.
6. Сверьте нестабильный API с документацией Node.js 24.

## 1. Взаимодействие со средой Node.js

Node.js — это среда выполнения JavaScript, а не язык и не веб-фреймворк. V8 компилирует и исполняет JavaScript, Node добавляет системные API, а libuv участвует в организации цикла событий и части фоновой работы.

JavaScript выполняется до ближайшей точки возврата управления. Затем runtime может обработать microtasks, перейти к следующей фазе event loop и вызвать готовые callbacks.

В контексте этого урока раздел связан с задачей: `package.json` — контракт проекта: `type`, `scripts`, `engines`, зависимости и метаданные.

Главный риск — заблокировать event loop синхронной операцией или большим вычислением и тем самым задержать все подключения процесса.

## 8. Импорт модулей

Формат файла определяется расширением и полем `type` в package.json. Смешивать ESM и CommonJS без явной границы нельзя: у них отличаются загрузка, значения служебных переменных и правила interop.

Поле `exports` ограничивает доступные точки входа пакета, а `imports` создаёт внутренние aliases. Это часть контракта поставки, а не косметическая настройка.

В контексте этого урока раздел связан с задачей: Команды `node --watch`, `node --env-file=.env`, `node --run <script>` и встроенный парсер аргументов уменьшают число учебных зависимостей.

Неявное смешение форматов приводит к ошибкам загрузки, неожиданному default export и различиям между локальным запуском и тестами.
